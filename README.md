 Car Colour Customization & Other Services

* Project Overview

This is an academic web application developed using Python Django. The project allows users to customize car colours, explore available services, and manage customer details through a simple and user-friendly interface.

* Features

- User Registration & Login
- Car Colour Customization
- Car Service Management
- Customer Information Management
- Order Management
- Admin Panel

 Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
